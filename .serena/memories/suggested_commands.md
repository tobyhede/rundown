# Suggested Commands

## Build
```bash
npm run build
```

## Test (all)
```bash
npm run test
```

## Test (specific package)
```bash
npx jest packages/cli/__tests__/services/template-renderer.test.ts
npx jest packages/core/__tests__/runbook/file-provider.test.ts
npx jest packages/parser/__tests__/helpers.test.ts
```

## Lint
```bash
npm run lint
npm run lint:fix
```

## Git
```bash
git status
git diff
git log --oneline -10
```
