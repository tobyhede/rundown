# Project Runbooks

Project-level runbooks for this repository, discovered automatically by `rd ls --all`.

Place runbooks in subdirectories by category (e.g. `review/`, `deploy/`).
Colocate implementation scripts alongside their runbook in a `scripts/` directory.

See [docs/guides/project-integration.md](../../../docs/guides/project-integration.md) for conventions and worked examples.
